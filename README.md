# My Isometric Retro Computer Room

A simple low-poly 3D scene with a retro computer setup and a hardware workbench.

## Files
This repository consists of two files:
1. `Isometric_Room.fbx` - The 3D model containing all meshes and layouts.
2. `Render_Preview.png` - A high-quality screenshot showing the finished composition.

## Model Layout
* **Retro Desk:** A boxy CRT monitor, a mechanical keyboard (modeled using a layout reference blueprint), floppy disk trays, scattered paperwork, a mug, and a desk chair.
* **Hardware Bench:** A secondary white desk positioned under the window cutout, populated with a smart soldering iron station, a circuit board design, and loose electronic microcomponents.
* **Room Details:** Light-wood floor geometry, floating textbooks, a desk lamp, and a geometric potted plant.

## Tracking Verification
All active modeling and composition hours were logged using the Lookout desktop client.
